# KeyFix AI — افزونه اصلاح زبان تایپ

[English](README.md) | فارسی

KeyFix AI یک افزونهٔ سبک برای تشخیص و اصلاح محلی متن‌هایی است که با چیدمان اشتباه صفحه‌کلید تایپ شده‌اند. با وجود نام محصول، از سرویس هوش مصنوعی ابری استفاده نمی‌شود و متن از مرورگر خارج نمی‌شود.

## نصب در Chrome
1. فایل ZIP را استخراج کنید.
2. در Chrome آدرس `chrome://extensions` را باز کنید.
3. `Developer mode` را روشن کنید.
4. روی `Load unpacked` بزنید و همین پوشه را که `manifest.json` در آن است انتخاب کنید.
5. برای فعال شدن در تب‌هایی که از قبل باز بوده‌اند، آن تب‌ها را Refresh کنید.

## امکانات
- پیشنهاد شناور داخل صفحه برای عبارت‌های فارسی یا انگلیسی که با چیدمان زبان اشتباه تایپ شده‌اند.
- اصلاح با یک کلیک؛ عبارت پیوستهٔ اطراف مکان‌نما اصلاح می‌شود و متن‌های اطراف دست‌نخورده می‌مانند.
- میانبر پیش‌فرض `Alt + Shift + F` برای متن انتخاب‌شده یا عبارت زیر مکان‌نما.
- گزینه فعال/غیرفعال کردن پیشنهاد و حالت تشخیص دقیق‌تر.
- رابط فارسی و انگلیسی؛ زبان اولیه با زبان مرورگر انتخاب می‌شود و انتخاب دستی از دکمهٔ بالای popup ذخیره می‌ماند.
- پردازش متن به‌صورت محلی؛ متن به سرور ارسال نمی‌شود.
- آیکون‌های PNG در اندازه‌های استاندارد Chrome و فونت Vazirmatn همراه افزونه؛ رابط برای نمایش فونت محلی به اینترنت نیاز ندارد.

## توسعه و آزمون
برای اجرای آزمون‌ها Node.js نسخهٔ ۲۲ یا بالاتر لازم است؛ پروژه وابستگی npm ندارد:

```sh
npm test
npm run check
```

## محدودیت‌ها
- اکستنشن در صفحات HTTP/HTTPS در Chrome یا مرورگرهای مبتنی بر Chromium کار می‌کند، نه در برنامه‌های مستقل ویندوز و نه در صفحات محافظت‌شده مانند `chrome://` یا Chrome Web Store.
- در بعضی ویرایشگرهای پیچیده مثل برخی محیط‌های مبتنی بر canvas یا ویرایشگرهای سفارشی، ممکن است نیاز به سازگاری جداگانه باشد.
- تشخیص بر اساس نگاشت محلی صفحه‌کلید و واژه‌نامهٔ داخلی است. برای واژه‌های شناخته‌شده، یک غلط تایپی نزدیک (مثل حرف اضافه یا تکراری) نیز اصلاح می‌شود؛ این قابلیت جایگزین غلط‌یاب عمومی نیست و سرویس هوش مصنوعی ابری استفاده نمی‌شود. حالت «تشخیص دقیق‌تر» برای عبارت‌های آشنای فارسی و انگلیسی محافظه‌کارانه‌تر است؛ با خاموش‌کردنش پیشنهادهای بیشتری می‌بینید.
- فونت Vazirmatn از فایل‌های محلی افزونه بارگذاری می‌شود؛ در صورت مشکل در بارگذاری، رابط از فونت جایگزین سیستم استفاده می‌کند.

## عیب‌یابی
اگر پیشنهاد داخل سایت ظاهر نشد، صفحه وب را یک بار Refresh کنید، پیشنهاد هنگام تایپ را از popup فعال کنید و با یک فیلد ساده متنی آزمایش کنید. اگر میانبر کار نکرد، به `chrome://extensions/shortcuts` بروید و یک کلید میانبر در دسترس انتخاب کنید.
